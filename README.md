# CellGlide website

Static site for https://<your-github-username>.github.io/cellglide

1. Create a **public** repository named `cellglide` on GitHub.
2. Upload every file in this folder to the repository root (drag-and-drop on github.com works).
3. Repository **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, folder `/ (root)`, Save.
4. After about a minute the site is live at `https://<username>.github.io/cellglide/`
   and the privacy policy at `https://<username>.github.io/cellglide/privacy.html`.

Give the first URL to Stripe as your business website and the second to the
Chrome Web Store as your privacy policy URL. When the extension is approved,
replace the two `#install` hrefs in index.html with the store link.
